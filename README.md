# GotaCheck León

## Descripción del proyecto

GotaCheck León es un prototipo de aplicación web orientado a los habitantes de León, Guanajuato, que permite consultar información relacionada con el suministro de agua por colonia y realizar reportes ciudadanos de fugas.

El prototipo representa también el seguimiento de los reportes mediante diferentes perfiles de usuario: Ciudadano, Supervisor / Gestor de Zona, Técnico de Campo y Administrador General.

Esta etapa corresponde al desarrollo Front-End del sistema, por lo que las funciones se representan mediante vistas web navegables y responsivas, sin depender todavía de un backend o una base de datos.

## Perfiles del sistema

### Ciudadano
Puede consultar el calendario de tandeo de agua de su colonia, visualizar el historial de sus reportes y registrar un nuevo reporte de fuga.

### Supervisor / Gestor de Zona
Puede consultar reportes, asignar fugas a cuadrillas y gestionar la programación del suministro de agua.

### Técnico de Campo
Puede consultar las órdenes de trabajo asignadas y registrar información y evidencias relacionadas con la atención de las fugas.

### Administrador General
Puede consultar y administrar usuarios, roles y permisos dentro del prototipo.

## Ejecución del proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Localizar el archivo `index.html`.
4. Abrir `index.html` en un navegador web.
5. Desde la página principal acceder al Inicio de Sesión.
6. Seleccionar uno de los perfiles disponibles.
7. Ingresar datos de prueba para acceder al dashboard correspondiente.

No es necesario configurar una base de datos o un servidor backend para visualizar esta versión del prototipo.

## Credenciales de demostración
